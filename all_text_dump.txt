1. Lineamientos obligatorios para el asesor 1.1. Escucha activa y validación: Escuchar sin interrumpir. Validar con empatía. Mostrar disposición para ayudar. Criterios para escalar a un supervisor: El asesor solo debe transferir o solicitar intervención de un supervisor cuando: El cliente insiste en que le comuniquen a un supervisor. Transferir siguiendo el protocolo de la operación. Si el supervisor NO está disponible: Registrar la solicitud en CRM. Informar con claridad el plazo de contacto. Qué digo / Qué no digo / Definición QUÉ DIGO QUÉ NO DIGO DEFINICIÓN Cable Drop - Cable que se conecta a los puertos de la CTO e ingresa al domicilio del cliente. Cable ethernet Cable de red / LAN / RJ45 Cable que nos permite conectar el router a nuestros dispositivos de manera directa. Caja / CTO CTO Caja que protege los empalmes de fibra entre la red principal y el domicilio de los clientes. Dirección IP IP / Protocolo de Internet Número que identifica nuestro dispositivo en Internet. DNS - Sistema de nombres de dominio. Funciona como la guía telefónica en Internet. Ubica las IP de los servidores de servicio al colocar el nombre, ejemplo: Facebook.com. IP Dinámica - IP pública que cambia cada cierto tiempo. IP Estática - IP pública que no cambia, siempre será la misma. IP Privada - Direcciones que identifican a nuestro router y dispositivos conectados a él. IP Pública - Dirección que identifica a mi router, como mi dispositivo principal de cara a la red de internet. También, identifica servidores en internet. Jumper / Cable amarillo Patch Cord Cable que conecta al cable Drop en la roseta con la ONT del cliente. NAT Network Address Translation Traducción de direcciones de red. Procedimiento que vincula tu IP privada a la IP Pública otorgada por tu operador para interactuar en Internet. Roseta - Caja que protege el empalme entre el cable de fibra de exteriores y el de interiores. Router / ONT ONT Dispositivo que convierte la señal óptica en señal digital en tu router para conectarte a Internet vía cable o WiFi. 3. ABC GAMER Enrutamiento: Cuando el Gamer ingresa a un juego de la lista, lo conectamos con el servidor más óptimo para dicho juego. Si abre otro juego, automáticamente localizamos el mejor servidor y conectamos al Gamer. Lag: Ping elevado, superior al promedio. Latencia: Tiempo de respuesta ante una acción en la red, medido en milisegundos. Pérdida de paquetes: Cuando el juego se queda congelado por algunos segundos durante la partida. Ping: Mide la latencia en milisegundos (ms). El ping promedio va a depender del juego y servidor elegido. SDwan: Red de área extensa, definida por software, que gestiona y controla de forma centralizada todos los componentes de hardware a través del software. Servidor: Lugar donde se puede elegir jugar. Mientras más alejado, mayor será el ping. IP Privada: Dirección que identifica a nuestro router y dispositivos conectados a él. IP Pública: Dirección que identifica a mi router como mi dispositivo principal para la red de Internet. También, identifica servidores en Internet. Jumper / Cable amarillo: Cable que conecta al cable Drop en la roseta con la ONT del cliente. NAT: Traducción de direcciones de red. Procedimiento que vincula tu IP Privada a la IP Pública de tu operador para que puedas interactuar en Internet. Roseta: Caja que protege el empalme entre el cable de fibra de exterior y de interior. Router: Dispositivo que convierte la señal óptica en señal digital en tu router, para conectarte a internet vía cable o WiFi. 4. 3. ABC GAMER Enrutamiento
Cuando el Gamer ingresa a un juego de la lista, lo conectamos con el servidor más óptimo para dicho juego. Si abre otro juego, automáticamente localizamos el mejor servidor y conectamos al Gamer. Lag: Ping elevado, superior al promedio. Latencia: Tiempo de respuesta ante una acción en la red, medido en milisegundos. Pérdida de paquetes: Cuando el juego se queda congelado por algunos segundos durante la partida. Ping: Mide la latencia en milisegundos (ms). El ping promedio va a depender del juego y servidor elegido. SDwan: Red de área extensa, definida por software, que gestiona y controla de forma centralizada todos los componentes de hardware a través del software. Servidor: Lugar donde se puede elegir jugar. Mientras más alejado, mayor será el ping. IP Privada: Dirección que identifica a nuestro router y dispositivos conectados a él. IP Pública: Dirección que identifica a mi router como mi dispositivo principal para la red de Internet. También, identifica servidores en Internet. Jumper / Cable amarillo: Cable que conecta al cable Drop en la roseta con la ONT del cliente. NAT: Traducción de direcciones de red. Procedimiento que vincula tu IP Privada a la IP Pública de tu operador para que puedas interactuar en Internet. Roseta: Caja que protege el empalme entre el cable de fibra de exterior y de interior. Router: Dispositivo que convierte la señal óptica en señal digital en tu router, para conectarte a internet vía cable o WiFi.

FORMATOS - CONTRATO DE CESIÓN DE POSICIÓN CONTRACTUAL (DNI A RUC, RUC A RUC, RUC A DNI, DNI A DNI) Y CONSTANCIA DE NO ADEUDO Instrucciones generales para llenar formatos - DNI A RUC / DNI A DNI / RUC A RUC / RUC A DNI Conoce cómo llenar el formato - DNI A RUC / DNI A DNI: El documento no debe presentar manchas ni borrones. Los datos deben ser legibles. El documento debe estar firmado por el titular actual y el nuevo titular. Completa todos los campos indicados. function showSection(id, navEl) {
document.querySelectorAll('.content-section').forEach(el => el.classList.remove('active'));
document.getElementById(id).classList.add('active');
document.querySelectorAll('.nav-item').forEach(el => el.classList.remove('active'));
if(navEl) navEl.classList.add('active');
window.scrollTo(0,0);
}
function toggleAccordion(btn) {
const item = btn.parentElement;
item.classList.toggle('open');
}
function expandAll() {
const activeSec = document.querySelector('.content-section.active');
activeSec.querySelectorAll('.accordion-item').forEach(acc => acc.classList.add('open'));
}
function collapseAll() {
const activeSec = document.querySelector('.content-section.active');
activeSec.querySelectorAll('.accordion-item').forEach(acc => acc.classList.remove('open'));
}
function copyText(btn, text) {
navigator.clipboard.writeText(text).then(() => {
const icon = btn.innerHTML;
btn.innerHTML = '
Copiado';
btn.style.color = '#10b981';
setTimeout(() => {
btn.innerHTML = icon;
btn.style.color = '';
}, 2000);
});
}
function toggleFav(btn) {
btn.classList.toggle('active');
if(btn.classList.contains('active')) {
btn.innerHTML = '
Guardado';
} else {
btn.innerHTML = '
Favorito';
}
}
